# Benesom Realtors Pvt Ltd

A responsive, editorial-style landing page for Benesom Realtors Pvt Ltd, a Lucknow-based real estate, farmland and property development company.

## Included

- Responsive navigation with mobile menu
- Hero section with rating/social proof
- Services for farm, farmland, luxury farmhouse, development and investing
- Featured spaces/projects section
- Contact enquiry form with client-side confirmation
- Responsive layout for mobile, tablet and desktop

## Run locally

Open `index.html` in a browser, or serve the directory with any static web server.

Replace the placeholder phone number, email, project details and Unsplash images with the company's final brand assets and contact information before launch.
